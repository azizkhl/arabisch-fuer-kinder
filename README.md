# 🐪 Arabisch für Kinder

**Eine maximal krasse und spaßige App, die Kindern Arabisch beibringt!**

Lernen • Schreiben • Aussprache • Spielen • Level für Level

![Lizenz](https://img.shields.io/badge/Lizenz-MIT-blue)
![Für](https://img.shields.io/badge/Für-Kinder-orange)

## ✨ Features

- **28 arabische Buchstaben** mit allen Formen (allein, Anfang, Mitte, Ende)
- **Aussprache** per Browser-Sprachausgabe (Arabisch)
- **Schreib-Übungen** auf dem Canvas – einfach nachzeichnen
- **Lustige Quizzes** (Erkennen, Laute, Wörter, Hören)
- **12 Level** mit Fortschritt und Sternen
- **Gamification**: Sterne sammeln, Level freischalten, Confetti!
- **Wunderschönes Design** – bunt, modern, kindgerecht
- **Komplett offline** nutzbar (nach dem Laden)
- **Responsive** – perfekt für Tablet & Smartphone

## 🚀 So startest du die App

### Einfach lokal öffnen
1. Lade den Ordner herunter oder clone das Repo
2. Öffne `index.html` im Browser (Chrome/Edge/Firefox empfohlen)

### Oder mit einem lokalen Server
```bash
# Mit Python
python -m http.server 8000

# Dann im Browser: http://localhost:8000
```

### GitHub Pages
Du kannst das Repo direkt als GitHub Pages hosten – dann läuft die App unter:
`https://azizkhl.github.io/arabisch-fuer-kinder/`

## 🎮 Level-Übersicht

1. **Erste Schritte** – ا ب ت ث
2. **Tiere & mehr** – ج ح خ د
3. **Weiter geht's** – ذ ر ز س
4. **Sch & Schwer** – ش ص ض ط
5. **Kehllaute** – ظ ع غ ف
6. **Fast geschafft** – ق ك ل م
7. **Die letzten** – ن ه و ي
8. **Buchstaben-Meister** – Alle 28 wiederholen
9. **Wort-Detektiv** – Wörter erkennen
10. **Schreib-Champion** – Schreiben üben
11. **Hör-Held** – Aussprache-Quiz
12. **Superstar** – Finales Challenge

## 🛠️ Technologie

- Reines **HTML + CSS + JavaScript** (kein Framework nötig)
- Web Speech API für Aussprache
- Canvas für Schreib-Übungen
- localStorage für Fortschritt
- Google Fonts (Nunito + Noto Naskh Arabic)

## 📱 Tipps

- Am besten auf einem **Tablet** spielen
- Arabische Stimme im System aktivieren für bessere Aussprache
- Chrome oder Edge liefern oft die besten Arabisch-Stimmen
